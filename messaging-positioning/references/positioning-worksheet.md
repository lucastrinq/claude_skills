# Positioning Worksheet

Work through these exercises in order. Do not skip steps. Each step builds on the previous one. If you get stuck, the problem is usually that an earlier step was not specific enough — go back and sharpen it.

This worksheet follows the Obviously Awesome framework by April Dunford, adapted into an executable format.

---

## Step 1: List Your Competitive Alternatives

**The question:** If your product did not exist, what would your target customer do instead?

**How to think about it:** This is NOT just a list of logo competitors. Most buyers are not choosing between you and a direct competitor — they are choosing between you and doing nothing, using a spreadsheet, asking an intern, or building something in-house. List every realistic alternative.

**Common traps:**
- Only listing direct competitors and ignoring the status quo
- Listing aspirational competitors you wish you competed with instead of the ones buyers actually evaluate
- Forgetting "do nothing" — which is the most common competitor in every category

**Exercise:** Fill in this table with at least 5 alternatives.

| Alternative | Type | What They Do Well | What They Do Poorly |
|-------------|------|-------------------|---------------------|
| | Direct competitor | | |
| | Direct competitor | | |
| | Adjacent category | | |
| | Manual/status quo | | |
| | Build in-house | | |
| | Do nothing | | |

**Example (for Velora):**
| Alternative | Type | What They Do Well | What They Do Poorly |
|-------------|------|-------------------|---------------------|
| Gainsight | Adjacent (CS platform) | Broad CS functionality, enterprise credibility | Onboarding is a module, not the focus. Complex to deploy. |
| Asana + spreadsheets | Manual/status quo | Familiar, flexible, already owned | No product data integration. Cannot predict churn. Does not scale. |
| Internal tool built by eng | Build in-house | Fully customized to their product | Competes with product roadmap. No AI. Maintenance burden. |
| Do nothing | Do nothing | Zero effort | Churn continues. CS team burns out. |

## Step 2: List Your Unique Attributes

**The question:** What capabilities or characteristics does your product have that alternatives do not?

**How to think about it:** Be brutally specific. Not "better UX" — what specific thing can a user do in your product that they cannot do in any alternative? Think about features, architecture, data, integrations, speed, methodology, and business model.

**Common traps:**
- Listing table-stakes features as unique attributes (e.g., "reporting dashboards" or "API access")
- Confusing "we do it better" with "we do something they do not" — only the latter is a unique attribute
- Including roadmap items that do not exist yet

**Exercise:** For each competitive alternative from Step 1, list what you can do that they cannot.

| Your Attribute | Which Alternatives Lack This? | All of Them? |
|---------------|-------------------------------|-------------|
| | | Yes / No |
| | | Yes / No |
| | | Yes / No |
| | | Yes / No |
| | | Yes / No |

**Keep only the attributes where "All of Them?" is Yes.** Attributes that only differentiate against some alternatives are weaker positioning foundations.

**Example:**
| Your Attribute | Which Alternatives Lack This? | All of Them? |
|---------------|-------------------------------|-------------|
| AI-driven churn prediction during the onboarding window (first 90 days) | All — CS platforms predict on mature accounts, not new ones | Yes |
| Dynamic workflows that adapt based on real-time product usage data | All — manual processes are static, CS platforms use playbooks not usage data | Yes |
| 4-day deployment with no engineering resources | Gainsight (3-6 months), in-house build (months), manual (N/A) | Yes |
| 40+ pre-built integrations | Some have integrations too | No — remove |

## Step 3: Translate Attributes to Value

**The question:** So what? For each unique attribute, what does it let the buyer DO, ACHIEVE, or AVOID?

**How to think about it:** Attributes are about your product. Value is about the buyer's life. The translation goes: "We have [attribute], which means you can [value]." If you cannot complete that sentence in a way that makes a buyer care, the attribute is not valuable — it is a feature.

**Common traps:**
- Stopping at the first "so what" instead of asking it three times (the real value is usually two layers deeper)
- Stating value in your language instead of the buyer's language
- Confusing technical capability with business outcome

**Exercise:** Apply the "So What?" chain to each unique attribute.

| Unique Attribute | So What? (Level 1) | So What? (Level 2) | So What? (Level 3 — the real value) |
|-----------------|--------------------|--------------------|--------------------------------------|
| | | | |
| | | | |
| | | | |

**Example:**
| Unique Attribute | So What? (Level 1) | So What? (Level 2) | So What? (Level 3) |
|-----------------|--------------------|--------------------|---------------------|
| AI-driven churn prediction during onboarding | You see which new customers are at risk | You intervene before they disengage | You prevent churn that was previously invisible until it was too late |
| Dynamic usage-based workflows | Onboarding adapts to what each customer has actually done | Every customer gets a relevant path, not a generic checklist | Time-to-value drops because nobody is stuck on irrelevant steps |
| 4-day deployment | You are live in less than a week | You see impact within the current quarter | You can prove ROI to your CFO before renewal of your current tools |

**The Level 3 value is what belongs in your messaging.** Levels 1 and 2 are supporting explanation.

## Step 4: Identify Who Cares the Most

**The question:** Which buyers have this pain the worst? Who would pay the most, switch the fastest, and evangelize the loudest?

**How to think about it:** You are looking for the segment where your unique value is not just nice-to-have but urgent. Think about: Who gets fired if this problem is not solved? Who has budget allocated? Who has tried alternatives and been disappointed? Who has the shortest sales cycle for your product?

**Common traps:**
- Defining the segment too broadly ("mid-market SaaS companies" is not a segment — it is a demographic)
- Picking the biggest addressable market instead of the best-fit market
- Confusing "people who could use this" with "people who will buy this urgently"

**Exercise:** Narrow your segment using these filters.

| Filter | Your Answer |
|--------|-------------|
| Company size / stage where the pain is worst | |
| Specific trigger that makes this urgent now | |
| Title of the person who owns this problem | |
| What they have already tried and why it failed | |
| How they would describe the problem in their own words | |

**Target segment statement:** "Our best customers are [company type] who are [experiencing trigger] and have [tried alternative] but found it [limitation]. The person who buys is [title] who is accountable for [metric]."

**Example:** "Our best customers are Series B-C SaaS companies who are experiencing first-90-day churn above 15% and have tried managing onboarding with spreadsheets and check-in calls but found it impossible to scale past 50 concurrent onboardings. The person who buys is the VP of Customer Success who is accountable for net revenue retention."

## Step 5: Select Your Market Category

**The question:** What frame of reference helps the buyer immediately understand what you are and why your strengths matter?

**How to think about it:** The market category sets expectations. If you say "CRM," buyers immediately know what to expect (contacts, pipelines, deals). Your category should make your unique value feel like an obvious strength, not a quirk.

**Decision framework — choose one:**

| Strategy | When to Use | Risk |
|----------|-------------|------|
| **Claim an existing category** | When a recognized category exists and you can credibly be the best in it | You inherit category expectations — including features you may lack |
| **Create a subcategory** | When you fit broadly in a category but have a distinct focus or approach | Requires education spend. Buyers may not recognize the subcategory yet. |
| **Create a new category** | When nothing existing captures what you do and you have the budget to evangelize | Extremely expensive. Requires 18+ months of consistent messaging. Only do this if you are well-funded and have market proof. |

**Exercise:** Test your category choice.

| Test Question | Your Answer |
|--------------|-------------|
| If I say "[your category]," does the buyer immediately understand approximately what the product does? | |
| Does this category make your unique attributes look like strengths (not oddities)? | |
| Are there existing buyers actively searching for solutions in this category? | |
| Can you credibly be seen as a leader in this category within 18 months? | |

If you answered "no" to any of the first three questions, reconsider your category.

**Example:** Velora chose "AI-powered customer onboarding platform" — a subcategory of customer success platforms. This works because:
- "Customer onboarding platform" is understood (inherits context from CS category)
- "AI-powered" differentiates from workflow-only tools
- The narrow focus on onboarding makes their speed and depth of onboarding features look like strengths, not limitations

## Step 6: Write the Positioning Statement

**The question:** Can you capture your positioning in one sentence that is specific, honest, and differentiated?

**Template:**
"For [target segment] who [situation/need], [product] is the [market category] that [key differentiator], unlike [primary alternative] which [limitation]."

**Rules:**
- Every word must earn its place. If you can remove a word without losing meaning, remove it.
- The statement should be specific enough that it could NOT describe a competitor. Read it and ask: could Company X also say this? If yes, rewrite.
- This is an internal alignment tool, not a tagline. Clarity beats cleverness.
- Write three versions and pick the sharpest one.

**Common traps:**
- Making it so broad it describes the whole category
- Using jargon the buyer does not use
- Including multiple differentiators (pick one — the strongest)
- Writing it as marketing copy instead of a clear strategic statement

**Exercise:** Write three versions.

| Version | Statement |
|---------|-----------|
| V1 | |
| V2 | |
| V3 | |

**Sharpness test for your chosen version:**
- [ ] Could a competitor say this honestly? (If yes, rewrite)
- [ ] Does a target buyer understand it without explanation? (If no, simplify)
- [ ] Is every claim provable today? (If no, remove the unprovable claim)
- [ ] Is it under 40 words? (If no, cut)

**Example:**
- V1: "For mid-market SaaS companies losing customers in the first 90 days, Velora is the AI-powered onboarding platform that predicts which customers will churn before they disengage, unlike CS platforms that only measure health after onboarding is over."
- V2: "For VP Customer Success leaders at scaling SaaS companies, Velora is the onboarding platform that uses product usage data to prevent early-stage churn, unlike spreadsheet-based processes that cannot scale or learn."
- V3: "For Series B-C SaaS companies with first-90-day churn above 15%, Velora is the AI-powered onboarding platform that identifies at-risk customers within hours of signup, unlike CS platforms where onboarding is a feature, not the focus."

**Chosen: V3** — Most specific segment, clearest differentiator, sharpest competitive contrast.

## What To Do With This Worksheet

Your completed positioning worksheet feeds directly into the messaging hierarchy:
- **Step 1-2** (alternatives + attributes) feeds the Competitive Landscape section
- **Step 3** (value translation) feeds the Key Message Pillars
- **Step 4** (target segment) feeds the Strategic Narrative and Persona Cards
- **Step 5** (category) feeds the Core Positioning layer
- **Step 6** (positioning statement) becomes the foundation for tagline, one-liner, and elevator pitch

Do not skip ahead to messaging before this worksheet is complete. Messaging without positioning is decoration without structure.
