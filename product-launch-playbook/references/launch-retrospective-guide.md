# Launch Retrospective Guide

Structured framework for evaluating launch execution and extracting lessons for future launches.

## When to Run Retrospectives

| Timing | Focus | Participants |
|---|---|---|
| **T+7** | Early signal check: adoption, bugs, support volume, immediate customer reaction | PMM + Product + Support |
| **T+30** | Full metrics review: are we tracking toward targets? Customer feedback themes. | PMM + Product + Marketing + Sales |
| **T+90** | Revenue impact assessment: win rate changes, pipeline influence, retention impact | PMM + Product + Sales + Leadership |

## T+7 Quick Check Template

Run this as a 30-minute standup, not a formal meeting.

**Adoption:**
- [ ] How many users/accounts have activated the feature? vs. target: ___
- [ ] What's the activation curve — front-loaded (launch excitement) or steady?
- [ ] Any segments adopting faster/slower than expected?

**Stability:**
- [ ] Support ticket volume related to the feature: ___
- [ ] Any P0/P1 bugs reported?
- [ ] Performance metrics within acceptable range?

**Customer Reaction:**
- [ ] Social media sentiment (positive/neutral/negative)
- [ ] Customer quotes worth capturing
- [ ] Any unexpected use cases emerging?

**Immediate Actions:**
- [ ] Anything that needs fixing before T+30?
- [ ] Any messaging that's not landing as expected?

### Launch Execution Scoring

Rate each dimension 1-5:

| Dimension | Score (1-5) | Notes |
|---|---|---|
| **Tiering accuracy** — was the tier appropriate for the actual impact? | | |
| **Timeline adherence** — did we launch on time? | | |
| **Asset quality** — were all assets ready and effective? | | |
| **Cross-functional coordination** — did handoffs work smoothly? | | |
| **Messaging effectiveness** — did positioning resonate with buyers? | | |
| **Sales readiness** — were reps prepared and equipped? | | |
| **Customer communication** — did customers hear about it and adopt? | | |
| **Support readiness** — was support able to handle questions? | | |
| **Metrics tracking** — did we measure what matters? | | |
| **Speed of iteration** — did we fix issues quickly when found? | | |

**Scoring interpretation:**
- 40+ = Excellent execution. Document what made it work.
- 30-39 = Good with specific improvement areas. Normal for most launches.
- 20-29 = Significant gaps. Identify root causes before next launch.
- Below 20 = Process breakdown. Needs a dedicated improvement initiative.
