# 4Ps Marketing Mix

## When to Use This Module

Activate 4Ps when doing a **full marketing mix audit**, evaluating **pricing or packaging strategy**, reviewing **channel effectiveness**, or preparing a **go-to-market for a new product or segment**. It's deliberately inactive by default because most day-to-day PMM work doesn't require a full 4Ps review — it adds value for strategic planning cycles, not tactical execution.

Do NOT use 4Ps as a substitute for messaging work (use Messaging & Positioning module) or launch planning (use Product Launch Playbook).

---

## The 4Ps Framework

| P | Question it answers | PMM's role |
|---|---|---|
| **Product** | What are we selling, and does it solve the right problem? | Define value, packaging, and differentiation |
| **Price** | What do we charge, and does it match perceived value? | Own pricing strategy and tier logic |
| **Place** | How do customers find and buy us? | Define and optimize distribution channels |
| **Promotion** | How do we create demand and communicate value? | Drive awareness, consideration, and conversion |

---

## P1: Product

### PMM's product lens (not engineering's)

PMM doesn't own the product — but owns how it's packaged, named, and positioned. The product questions PMM must be able to answer:

- **Core value**: What is the single most important outcome we deliver?
- **Differentiation**: What do we do that the closest alternative cannot match?
- **Packaging**: How are features grouped into tiers? Does the packaging match buyer mental models?
- **Naming**: Do product/feature names communicate value or require explanation?
- **Roadmap signal**: What's coming that will shift the positioning? When should PMM prepare?

### Product-Market Fit Audit (quick)

| Signal | Green | Yellow | Red |
|---|---|---|---|
| Retention / NRR | >110% | 90–110% | <90% |
| "Very disappointed" score (Sean Ellis) | >40% | 25–40% | <25% |
| Feature adoption of core value | >60% of users | 40–60% | <40% |
| Time to first value | <1 day | 1–7 days | >7 days |
| Unprompted referrals | Common | Occasional | Rare |

If 2+ signals are Red, there is a product-market fit problem — no amount of promotion will fix it.

## P2: Price

### Pricing Strategy Selection

| Model | Best for | Risk |
|---|---|---|
| **Per seat / user** | Collaboration tools, SaaS with team adoption | Penalizes growth; customers cap users |
| **Usage-based** | Infrastructure, API, consumption products | Revenue unpredictability |
| **Tiered flat fee** | Products with distinct buyer segments | Complex to communicate |
| **Value-based** | Products with quantifiable ROI | Requires strong sales conversation |
| **Freemium** | High volume, low CAC products with viral loop | Conversion rate pressure; support cost |

### Pricing Audit Questions

1. Does our price anchor to the value we deliver, or to our cost?
2. Is there a pricing tier for each of our 3 main personas?
3. What's our win rate at current price points vs. 6 months ago? (Trend matters more than absolute)
4. Where in the funnel does pricing become an objection? (Discovery = wrong ICP. Late stage = packaging problem.)
5. What does our most common discount tell us? (Discount pattern = pricing problem location)

### Price-Value Matrix

Plot your tiers against perceived value to find misalignments:

```
HIGH VALUE
    |   [Tier 3 should live here]
    |
    |        [Tier 2]
    |
    |   [Tier 1]
LOW ─────────────────── HIGH PRICE
```

If lower tiers offer too much value for their price, you're leaving money on the table. If higher tiers are priced above perceived value, they won't convert.

## P3: Place (Distribution)

### Channel Audit

| Channel | Current contribution | CAC | Time to close | Scalability | Verdict |
|---|---|---|---|---|---|
| Inbound / SEO | | | | | |
| Paid search / social | | | | | |
| Outbound SDR | | | | | |
| Partner / reseller | | | | | |
| Product-led / self-serve | | | | | |
| Events / field | | | | | |
| Analyst / press | | | | | |

For each channel: if CAC × average close time is worse than your best channel by >2×, either fix it or deprioritize it.

### Channel-ICP Fit

Match channels to where your ICP actually discovers products:
- Enterprise buyers: peer recommendations, analyst reports, sales outreach
- Mid-market: G2/review sites, LinkedIn, content marketing
- SMB / self-serve: SEO, product-led, social proof, community

Misalignment between channel investment and ICP discovery behavior = wasted CAC.

## P4: Promotion

### Demand Generation Mix Audit

| Stage | Objective | Typical vehicles |
|---|---|---|
| **Awareness** | Make ICP aware of the problem and our category | Thought leadership, SEO, social, PR |
| **Consideration** | Help ICP evaluate us seriously | Case studies, demos, comparison content, G2 reviews |
| **Decision** | Remove barriers to purchase | Free trial, ROI calculator, customer references, pricing transparency |
| **Expansion** | Drive upsell and referral | Customer marketing, in-product nudges, community |

PMM's role: own the message at each stage, not just the top of funnel.

### Promotion Audit Questions

1. Is our content mapped to buyer stage, or is it all awareness-level?
2. Do we have case studies that match our top 3 ICP verticals?
3. What's our content-to-conversion ratio? (Traffic → trial/demo)
4. Are we present on the channels where our ICP seeks peer recommendations?
5. Does our promotion reinforce our positioning, or does it drift into feature-listing?

## 4Ps Synthesis Output

After completing a full 4Ps audit, produce a one-page summary:

**Strongest P**: [Which P is working well and why]
**Weakest P**: [Which P has the biggest gap]
**Top 3 recommended actions**: Ranked by impact/effort, with owner and timeline
**The interconnection to watch**: [How one P's weakness is likely affecting another — e.g., pricing friction undermining promotion ROI]
