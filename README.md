# claude_skills
The Github repo where all of my claude skills live happily. This is a living repo, meaning that it will be shared between my devices and will be updated on a constant basis.

Claude-efficiency skills: 
- metaprompt-builder — Turns a rough task into a structured, high-quality prompt when a task needs more depth or rigor before execution.
- pdf-large-image-heavy — Reading strategy for long, image-heavy PDFs (extract text first, then rasterize or OCR only where needed).
- skill-creator-plus — Builds, edits, and evaluates Claude skills (SKILL.md files) — for making new skills, not using existing ones.
- token-thrift — Makes any large or long-running task use fewer tokens without losing output quality.
- caveman — Ultra-compressed communication mode that cuts token usage while keeping technical accuracy, for quick, no-fluff answers.

Content Creation: 
- content-ideation-pipeline — Turns raw customer signal (calls, reviews, support tickets) into concrete content ideas.
- blog-writing-methodology — Structures and drafts blog posts from scratch (outline, brief, or full draft), following proven long-form content principles.
- email-newsletter-copy — Writes and reviews newsletter and cold outbound email copy: subject lines, hooks, CTAs.
- linkedin-post-craft — Helps write and structure LinkedIn posts, fix low-engagement posts, and generate hooks or ideas when stuck.
- opengraph-image — Generates the preview image (og:image) that shows up when a link is shared on LinkedIn, Slack, etc.

Strategy & Positioning:
- messaging-positioning — Builds positioning statements, messaging hierarchies, and value propositions for a product or offer.
- pmm-audit-icp-4ps — Builds ICP/persona definitions (JTBD) and 4Ps marketing-mix audits, or orchestrates a full multi-area PMM audit.
- product-launch-playbook — Generates a full launch plan: strategic brief, workback schedule, asset matrix, RACI, go/no-go checklist.
  
Competitive & Sales: 
- sales-enablement-assets — Creates sales collateral: one-pagers, demo scripts, pitch decks, ROI calculators, objection guides.
- competitive-intelligence — Builds battlecards, pre-call prep, and objection handling for "us vs. competitor X" positioning questions.
- win-loss-analyzer — Analyzes closed deals and sales transcripts to find why you're winning or losing, for QBRs or competitive reviews.
